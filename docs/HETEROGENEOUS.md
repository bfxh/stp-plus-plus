# §16 异质混合语料：曲率在选"域"，不是在选"价值"

§14 的 2.39× 与 §15 的"不迁移"，差别来自语料本身。于是最后一组实验把语料换成**三分域混合**
（Python 代码 / 英文对话 / 中文维基，各 1.2M token，round-robin 交错成 6729 个 512-block），
并加了一个关键控制：**域内分层**（保持 1:1:1 的域配比，只在每个域内部按分数选 25%）。

**结论：曲率首先是域探测器；去掉域混杂之后，按曲率选"最弯 25%"反而最伤（+13.2% ppl）。
在这个预算下，唯一安全的选择器是"均匀随机"。**

---

## 16.1 语料构建

| 来源 | 数据集 | 字段 | 用量 |
|---|---|---|---|
| code | `code_search_net`（python, validation） | `whole_func_string` | 1.20M token / 2243 block |
| chat | `HuggingFaceH4/ultrachat_200k`（train_sft 分片 0） | `messages` 拼成对话 | 1.20M token / 2243 block |
| zh | `wikimedia/wikipedia`（20231101.zh 分片 2） | `text` | 1.20M token / 2243 block |

`scripts/build_mixed_corpus.py`：各源独立 tokenize → 切 512-block → 按 `code, chat, zh`
round-robin 交错 → 留最后 300 块作测试。交错是刻意的：任何随机子集都保持 1:1:1，
选数据的效应才可比。测试集 ppl 也按同一混合比例计算。

## 16.2 分数与域的关系（本节的核心证据）

| 域 | block | 曲率 mean±sd | 基座 NLL mean±sd | 域内 corr(κ, NLL) |
|---|---|---|---|---|
| 全体 | 6729 | 1.4224 ± 0.0273 | 2.6757 ± 0.8633 | 0.216 |
| code | 2243 | 1.4302 ± 0.0282 | 2.3896 ± 0.5060 | −0.203 |
| chat | 2243 | 1.4054 ± 0.0192 | 2.0709 ± 0.5809 | −0.053 |
| zh | 2243 | 1.4314 ± 0.0253 | 3.5667 ± 0.6330 | +0.167 |

```
曲率最高 25% 的域构成：code 47.1% / chat 5.6% / zh 47.2%
曲率最低 25% 的域构成：code 20.8% / chat 64.0% / zh 15.2%
NLL  最高 25%（最难）的域构成：code 5.2% / chat 6.5% / zh 88.2%
曲率最高 ∩ NLL 最难 = 37.5%（随机基线 25%）
```

- **曲率 = 域探测器**：几乎把所有对话判成最平（64% 的 bottom-25% 是 chat），把代码与中文判成最弯
  （各约 47%）。它与"哪条数据值得学"无关，只与"文本是否像流畅自然语言"有关。
- **NLL = 难度探测器**：最难 25% 里 88% 是中文——对英文为中心的 1B 模型，中文就是最难的域。
- 两个键的**域内**相关接近 0（−0.203 / −0.053 / +0.167）：总体那个 0.216 全部来自**跨域方差**。

## 16.3 不分层：四臂 × 曲率（3 seed，120 步 × bs 4 = 245,760 token）

| 臂 | n | mean ppl | sd | Δ | t | 相对 |
|---|---|---|---|---|---|---|
| 全量（6729 块） | 3 | **6.7403** | 0.0275 | — | — | — |
| 随机 25% | 3 | 6.6863 | 0.0654 | −0.0540 | −1.43 | −0.8% |
| 曲率最高 25% | 3 | **7.4704** | 0.1880 | **+0.7301** | **6.73** | **+10.8%** |
| 曲率最低 25% | 3 | 6.9925 | 0.1120 | +0.2522 | 3.90 | +3.7% |

两个方向都变差，且"最弯"比"最直"更差——因为最弯的那 25% 基本等于 **code+zh 去掉 chat**，
最直的那 25% 基本等于 **chat 去掉 code+zh**。测试集是 1:1:1，失去任何一个域都要付 ppl。

## 16.4 不分层：按基座 loss 排序

| 臂 | n | mean ppl | sd | Δ | t | 相对 |
|---|---|---|---|---|---|---|
| loss 最难 25%（88% 中文） | 3 | 6.7668 | 0.0091 | +0.0265 | 5.06 | +0.4% |
| loss 最易 25%（几乎全 chat） | 3 | **8.5240** | 0.0807 | **+1.7837** | **38.30** | **+26.5%** |

§15 里"丢掉最易 25% 有 −0.4% 收益"的规则，在异质语料上**变成 +26.5% 的灾难**：
因为"最易"恰好是 chat 域，等于把训练集变成"没有对话"。

## 16.5 域内分层（关键对照：域配比固定为 1:1:1）

| 臂 | n | mean ppl | sd | Δ | t | 相对 |
|---|---|---|---|---|---|---|
| 域内随机 25%（`srand`） | 3 | **6.6545** | 0.0540 | −0.0858 | −2.75 | −1.3% |
| 域内曲率最高 25%（`shi`） | 3 | **7.6303** | 0.1188 | **+0.8900** | **12.97** | **+13.2%** |
| 域内 loss 最难 25%（`shi`） | 3 | 7.4005 | 0.0599 | +0.6602 | 19.09 | +9.8% |

去掉域混杂后，结论没有变好，反而更清楚：

- **域内最弯的 25% 比不分层还差**（7.63 vs 7.47）：在每个域里，曲率最高的是**最不典型**的块
  （代码里的长注释/畸形表达式、中文里的表格/外文/模板残留、对话里的乱码），它们是噪声而不是价值。
- **域内最难的 25% 同样差**（7.40，+9.8%）：这个预算下"难"≈"离群"，学它等于把容量花在长尾噪声上。
- **唯一不亏的是均匀随机**（−1.3%，甚至略好于全量——245k token 的固定预算下，
  把采样池从 6729 收到 1682 相当于减少重复抽样，属于预算效应而非"选数据"）。

## 16.6 三节合起来的判读

| 说法 | 合成块集（§14） | wikitext（§15） | 三分域混合（§16） |
|---|---|---|---|
| 曲率最高 25% 训练 | **−3.4%（2.39×）** | +0.4% | **+10.8%** |
| 曲率最低 25% 训练 | **+20.6%** | +0.1% | +3.7% |
| 丢最易 25%（loss 排序） | 未测 | **−0.4%** | **+26.5%** |
| 均匀随机 25% | −0.1%（打平） | −0.0% | **−0.8%（略优）** |

**统一解释：选数据的收益 = 语料中"有害数据占比"。**
§14 的合成集里，最直的 25% 是真正的退化块（重复/无信息），剔除它是净赚，所以曲率看起来像"价值信号"；
真实自然文本里有害占比很低，任何 25% 的裁剪都在丢分布覆盖，选数据必然亏。
曲率在异质语料上退化成域分类器，一旦用它选数据，就是在悄悄改域配比。

**因此，可对外的最终结论只有三条：**

1. STP 的几何量是一个**文本风格/域探测器**，不是样本价值函数；
   论文的 16× 与我们的 2.39× 都诞生于"有害占比很高"的语料，不能当通用缩放定律讲。
2. 固定域配比下，**块级选择无一例外是亏的**（域内曲率 +13.2%、域内难度 +9.8%），
   均匀随机是唯一安全的选择器；真实语料上的"丢尾部"只在同质语料有效（§15，−0.4%）。
3. **真正能动 ppl 的杠杆是"token 在域间的配比"**，不是"块的质量分"：同样 88% 中文，
   域内随机把中文从 8.68 拉到 7.63（−12.1%）、总体 −1.5%；而"最难 88% 中文"只到 8.05。
   换句话说，难数据选择的正效应全部来自"多给该域 token"。**按域报 ppl 才能看见这件事。**

## 16.8 分域 ppl 拆解（单 seed 82，关键对照）

混合 ppl 是一个加权平均，会把"某个域被救活/被打死"完全掩盖。给 `stpp.pretrain` 加
`--domains 3 --domain_names code,chat,zh`（test 块 `i%3` 分域），对每个臂重跑一次：

| 臂 | overall | code | chat | zh | Δcode | Δchat | Δzh |
|---|---|---|---|---|---|---|---|
| 全量 | 6.709 | 5.940 | 5.775 | 8.682 | — | — | — |
| 曲率最高 25% | 7.311 | 5.897 | 6.029 | 10.606 | −0.04 | +0.25 | **+1.92** |
| 曲率最低 25% | 6.888 | 5.971 | 5.658 | 9.455 | +0.03 | −0.12 | +0.77 |
| 随机 25% | 6.649 | 5.911 | 5.750 | 8.530 | −0.03 | −0.03 | −0.15 |
| loss 最难 25% | 6.769 | 6.170 | 6.114 | **8.047** | +0.23 | +0.34 | **−0.64** |
| loss 最易 25% | 8.447 | 5.942 | 5.652 | **16.860** | +0.00 | −0.12 | **+8.18** |
| 域内曲率最高 25% | 7.605 | 5.909 | 5.763 | 12.250 | −0.03 | −0.01 | +3.57 |
| 域内 loss 最难 25% | 7.450 | 5.954 | 5.787 | 11.442 | +0.01 | +0.01 | +2.76 |
| **对照：同配比(88/5/7)域内随机** | **6.608** | 6.120 | 6.103 | **7.627** | +0.18 | +0.33 | **−1.06** |

读法：

- **loss 最易 25% 的 +1.78 全是中文**（zh +8.18，code/chat 不变或略好）：它等于"不给中文 token"，
  混合 ppl 的灾难只是域覆盖缺失，不是"学了坏数据"。
- **loss 最难 25% 是唯一让难域变好的臂**（zh −0.64，−7.3%），代价是 code +0.23、chat +0.34——
  **拿英文换中文**。混合 ppl 的 +0.027 把这个交换完全掩盖了。
- **决定性的对照**：同样 88% 中文的配比，但域内**随机**选（`mixhi`），zh 是 **7.627**，
  比"最难 88% 中文"的 8.047 更好，overall 6.608 也更好。
  ⇒ **难数据选择带来的收益，全部来自"多给这个域 token"，不是"挑出这个域里最难的块"。**
  在同一域内，随机优于挑难。

> 加 `mixhi` 对照的方式：`scripts/build_mixhi.py` 按 nll-hi 的域构成（zh 1480 / code 88 / chat 114）
> 在域内随机抽，再用 `--train_ids` 训练——这样"配比"与"难度"两个变量就分开了。

## 16.9 边界

1. **域标签按 `i % 3` 推断**，round-robin 的构造使"域"与"曲率高低"结构性耦合；这正是要暴露的混杂，
   但也是本节能"证明曲率=域探测器"的原因，不能反过来证明"曲率无用"。
2. **3 个域、每域 1.2M token、单层（15）、单池大小（25%）**；域数与配比会改变结论。
3. **n=3 用于混合 ppl（±0.05–0.19）；分域拆解与 `mixhi` 对照是单 seed（82）**，
   用于机制解释而非效应量；ppl 逐 run 确定（同 seed 复跑逐位一致）。
4. **245,760 token 只覆盖 480/6729 块（7%）**；更长训练、更大预算下，"难数据"可能转为正收益
   （hard-example mining 的文献通常在多 epoch 设定下成立）。
5. **ppl 在混合测试集上平均**：任何偏离 1:1:1 的训练集都会因域覆盖缺失被罚，
   16.8 的分域拆解是为了把这个罚项显式化，不能消除它。
6. **`mixhi` 的 88/5/7 是照抄 nll-hi 的实测构成**，不是独立设计的配比；它只用于对照，
   不能被读成"最优配比是 88% 中文"。
