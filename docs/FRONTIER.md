# §17 怎么真的"突破缩放定律"：文献地图 + 可执行阶梯

> 目标不是喊口号，而是把"训练效率"变成一个可测的量：在同算力下把 ppl-vs-tokens 曲线往左下推，
> 并检验**曲线形状**（幂律 → 指数）是否真的变了。

---

## 17.1 "突破缩放定律"的数学含义

数据侧的缩放定律通常写成

```
L(D) = L∞ + A · D^(−α)          （幂律：每多 10× 数据，损失降一个固定比例）
```

两种"突破"方式，强度完全不同：

| 方式 | 形式 | 含义 | 现实收益 |
|---|---|---|---|
| **平移常数** | `A` 变小 | 同样的 D 得到更低 loss | 1.2–2×（可复现、常见） |
| **改指数** | `α` 变大 / 变指数衰减 | 每份新数据的信息量不再衰减到 0 | 3–10×（需要"高质量剪枝度量"） |

Sorscher 等人证明：**只有当剪枝度量足够好时，误差才会从幂律转成指数**；度量不完美时，
曲线会先指数、再跌回一条由度量质量决定的幂律下包络。他们把 ImageNet 剪掉 20% 不掉点，
并给出一个可检验的推论：**"保留难样本"还是"保留易样本"取决于数据总量**——
数据稀缺时易样本承载粗粒度特征，数据充裕时难样本才提供细粒度信息；
最优保留比例 `f*(D)` 随数据量增长。

这条推论，正好解释我们 §14–§16 的三次失败（见 17.3）。

## 17.2 文献地图（只列能直接用的）

| 工作 | 核心机制 | 关键数字 | 对我们的用处 |
|---|---|---|---|
| **Sorscher 2022**（NeurIPS Outstanding） | 数据剪枝改缩放指数 | ImageNet −20% 不掉点；理论：指数缩放需好度量；`f*` 随数据量增长 | 定义"真突破"的判据；给出 hard/easy 翻转的机制 |
| **Score-based pruning 失效**（arXiv 2302.06960） | 高压缩（≤30%）下打分剪枝会被随机打败 | 证明分布偏移；给"90% 打分 + 10% 随机探索"校准方案 | 解释我们 25% 剪枝为何全亏；给出修法 |
| **RHO-1 / SLM**（NeurIPS 2024 oral） | **超额损失**（当前模型 − 参考模型）选 token，逐 batch 保留 top k% | k=60–70%；15B math 上快 5–10×；3% token 追平 DeepSeekMath | **我们缺的就是"参考模型"这一步** |
| **Data Mixing Laws**（ICLR 2025） | 用 log-linear 函数拟合 loss vs 域配比，再嵌套 scaling law 外推 | 1B/100B token 上等效 **+48% 步数** | §16.8 的"配比杠杆"正是它的实证 |
| **DoReMi**（NeurIPS 2023） | 280M 代理模型 + Group DRO 求域权重 | Pile 上 **2.6× 更少步数** | 配比优化的低成本实现 |
| **Deduplicating**（ACL 2022） | 精确子串 + MinHash 去重 | 数据小 **19%**；同精度更少步；ppl 最多 −10% | 最稳、最便宜的一档收益 |
| **SemDeDup**（2023） | 嵌入 k-means 去"语义重复" | LAION −50% 几乎不掉；**C4 −15%** | 文本语义冗余的量化 |
| **D4**（NeurIPS 2023 D&B） | 去重 + 多样性选择（SSL 原型） | 6.7B 上 **20% 效率**、下游 +2% | "去重后再选"的组合证据 |
| **Muennighoff 2023**（JMLR 2025） | 数据受限下的重复训练定律 | ≤4 epoch 几乎免费；`R*≈15`（~16 epoch 半衰）；40 epoch 无价值 | 决定我们的实验预算上限（别超 4 epoch） |
| **FineWeb-Edu**（NeurIPS 2024） | 用 70B 标注训小分类器做教育质量过滤 | 去掉 92%，MMLU 上 **10× 更少 token** | "质量过滤"是最强单杠杆 |
| **多语 model-based filtering**（2025） | 多语种结构化/知识密度分类器 | 15% token 追平基线 MMLU | 中文域可照做 |

## 17.3 我们的三个失败，文献里都有解释

| 我们测到的 | 文献解释 | 因此下一步该做什么 |
|---|---|---|
| §14 曲率选 25% 在合成集 +2.39×，真实语料为负 | 曲率是**域/风格探测器**；不是"价值函数"。Sorscher：度量必须排序"信息量"，不是"异常度" | 换度量：**超额损失**（RHO） |
| §16 域内最难 25% 掉 9.8%；随机最好 | 高压缩（≤30%）下打分剪枝被随机打败（2302.06960）；数据稀缺时应保留**易**样本（Sorscher） | ① 提高保留比例到 50–80%；② 保留 10% 随机探索；③ 用参考模型去掉"不可学"的难 |
| §16.8 真正有用的是"给中文多分 token" | 这就是 Data Mixing Laws / DoReMi 的结论：**配比**是第一杠杆 | 直接拟合 mixlaw，按目标 ppl 求最优配比 |
| loss 最难 25% 让中文 −0.64 但英文 +0.3 | 绝对 loss 混合了"难"与"不可学"；参考模型差分能消掉后者 | RHO 的 excess loss 正是这个差分 |

一句话：**我们已经有 RHO-1 的 90%，只差一个参考模型和 token 级（而不是块级）的选择。**

## 17.4 五级实验阶梯（每级都可证伪）

### L0 基线曲线（必须先做，2 小时）

- 语料：混合 6729 块（code/chat/zh）。
- 点：120 / 240 / 480 / 960 步（bs4×512 → 245k / 491k / 983k / 1.97M token），3 seed。
- 拟合 `L(D)=L∞+A·D^(−α)`，得到我们这台机器上的 α 与 L∞。
- **判据**：α 的 95% CI 要窄于 ±0.05，才能谈"改指数"。

### L1 去重（最便宜的一档，1 小时）

- 精确 13-gram 重叠去重（跨块）→ MinHash 近似去重 → 语义去重（复用第 15 层 mean 向量做 k-means，阈值扫描）。
- **预测**：code/chat 去 20–40%，zh 去 10–20%；同 ppl 下省 token。
- **判据**：在 L0 曲线上，去重版达到基线 ppl 所需 token 减少 ≥15%，且 3 seed 一致。

### L2 超额损失选 token（最可能出真结果，3 小时）

- 参考模型：同架构、在"高质量子集"（如 wikitext 散文 + 人工筛的 code/chat）上训 200 步。
- 给全部 6729×512 token 打 `L_ref`（一次前向，存 float16 ~7MB）。
- 训练时逐 batch 计算 `L_θ − L_ref`，只对 top-k% 的 token 回传（k=60/70），**上下文全保留**。
- **预测**：等 token 下 ppl −5~15%；等 ppl 下省 1.5–2.5× token。
- **判据**：k 扫描出现单调最优；与"同 k 的随机 token"对照显著（t>3）。

### L3 配比定律（把 §16.8 变成可预测工具，2 小时）

- 在 3 域上跑 6–9 个配比点（每点 120 步、1 seed），拟合 log-linear：
  `L_i(r) = c_i + k_i · exp(Σ_j t_ij r_j)`，再按目标（总体 ppl 或某域 ppl）求最优 `r*`。
- **预测**：在留出的 2 个配比上，预测误差 <0.05 ppl。
- **判据**：预测的最优配比在实际训练中打败 1:1:1 与"全量"。

### L4 剪枝比例的缩放（"改指数"的正面测试，4 小时）

- 语料扩到 4×（约 27k 块，多下载 2 个 zh 分片 + 2 个 code 分片 + 1 个 chat 分片）。
- 保留比例 `f ∈ {10%, 25%, 50%, 100%}`，每个 f 在**两个数据总量**（1×、4×）上各跑一个点。
- 关键看两件事：
  1. `L(f·D)` 对 `f·D` 的斜率是否比基线幂律更陡（Sorscher 的指数签名）；
  2. **hard vs easy 的方向是否随数据量翻转**（`f*` 预测）。
- **判据**：在 4× 数据上"保留难样本"开始为正，而 1× 上为负 → 复现了 Pareto 翻转，这才是真"突破缩放定律"的证据。

### L5 组合（终局，1 天）

`去重 → 超额损失 token 选择（k=60）→ 配比 law 选 r*` 三件套叠加，在 L0 曲线上量：
- 同 ppl 省多少 token（目标 ≥2×）；
- 曲线指数是否变化（目标：局部斜率 > 基线 α）。

## 17.5 目标与判据（写进论文的标准）

1. **主指标**：`D_base(L) / D_method(L)`（达到同一 ppl 所需 token 之比），3 seed，bootstrap CI。
2. **次指标**：曲线局部斜率 `dlogL/dlogD` 是否比基线更陡（指数签名）。
3. **反例标准**：若某方法只在 120 步有效、240 步就消失，则判定为"预算伪影"，不能写成数据效率。
4. **诚实边界**：1B/8GB、ppl-only、6.7k–27k 块；任何倍数都必须标注是"本区制"。

## 17.6 风险（先说清楚）

- **参考模型选错**：若 `L_ref` 来自"太干净"的语料，excess loss 会偏向"风格差异"而不是"可学信息"——这正是 RHO 的已知风险。控制：参考模型与目标同分布、只用 200 步、并做"参考模型换成基线自身"的对照。
- **token 级选择的成本**：每步多一次参考 loss 查表（预存），几乎零成本；但 `L_θ` 已在前向里，直接可用。
- **epoch 上限**：任何裁剪后池子都要保证 ≤4 epoch（Muennighoff）。6729 块 → 剪到 50% 后仍有 3.4M token，245k/run 只有 0.07 epoch，安全。
- **度量天花板**：Sorscher 说度量不完美会退回幂律。所以 L2/L4 必须报告"斜率"，不能只报单点倍数。

## 17.7 今晚的排期（按性价比）

| 顺序 | 实验 | 时长 | 产出 |
|---|---|---|---|
| 1 | L0 基线 240/480/960 三点 ×3 seed（9 run） | ~32 min | 基线曲线与 α |
| 2 | L1 精确+语义去重（CPU/前向） | ~20 min | 去重率与对照池 |
| 3 | L2 参考模型 + excess-loss token 选择（k=60）+ 3 seed | ~40 min | 第一个可能为正的"选择"结果 |
| 4 | L3 配比 6 点 ×1 seed | ~30 min | mixlaw 拟合 |
| 5 | L4 4× 语料 + f 扫描（先 1×/4× 各两点） | ~50 min | Pareto 翻转检验 |

合计约 3 小时机时，全部可在一晚上跑完；每一步都有明确的"证伪条件"，不会出现"跑完不知道算不算成功"。
