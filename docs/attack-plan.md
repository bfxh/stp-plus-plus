# 怎么比 STP 更强

> ⚠️ **本文件是"计划"，不是"结论"。** 五 seed 跑完后的实测判定见 **[../RESULTS.md](../RESULTS.md)**：
> 五条攻击路线里，两条打平（−0.27 / −0.73 点），三条掉点（−4.53 / −3.80 / −4.33），**没有一条赢**。
> 下面保留当初的推理链，方便对照"哪一步的预期被数据打掉了"。

> 目标论文：Semantic Tube Prediction（Huang / LeCun / Balestriero，arXiv:2602.22617，OpenReview poster）
> 官方代码：`galilai-group/llm-jepa`，`--linear=random_span`

---

## 0. 一句话

STP 的核心不是"正则化"，而是一个**几何断言**：

> 无误差的隐状态轨迹 ≡ 语义流形上的测地线 ≡ **局部直线**。

所以它把"偏离这条直线"的部分定义为噪声并压掉。**要赢它，最省力的路不是把它的正则项调得更好，而是证明这条断言只是一阶近似，然后用更弱的假设换更强的结论。**

---

## 1. 复现口径（必须先对齐，否则一切比较无效）

官方实现（`stp.py::compute_loss`, `linear="random_span"`）：

```python
# 在 [start, end) 里随机切一段 [p0, p1)
v_patch = h[p1-1] - h[p0-1]
v_out   = (h[p0-1] - h[start-1]) + (h[end-1] - h[p1-1])
loss    = 1 - cos(v_out, v_patch)
```

`stpp/geometry.py::stp_random_span` 逐项照抄这个算子，包括 `length_adjustment` 的 cosine_like / jaccard_like 权重。论文正文写的是三点式 `1 - cos(h_t - h_r, h_r - h_s)`，也单独实现了（`stp_triplet`）。

任何"比它强"的结论，都必须先在这套口径下把它的 16× 复现出来——否则对比的是空气。

## 2. 五条攻击线，逐条对应到代码

### A. 直线假设 → 曲率预算（`curv_budget`）

**它的问题**：真实轨迹是曲线。后继工作（arXiv:2604.18464）用 3 层 MLP 比线性外推好 3–12×；本项目在 Llama-3.2-1B 上实测是 **6.3× / 12.2× / 22.7×**（m=1/2/3）。把轨迹摁成直线，等于把可预测的真实结构一起罚掉。

**官方仓库里已经有 `linear="curvature"` 基线**，它是"惩罚所有转角"——同样过头。

**我们的做法**：

```
κ_i = ‖ (h_i - h_{i-1})_⊥chord ‖ / ‖ chord ‖        # 无量纲离散曲率
L   = mean_i relu(κ_i - τ)^2,   τ = EMA(观测 P90 曲率)
```

只罚超出"自然弯曲预算"的那部分。数学手术很小，但假设从 `C¹ 直线` 变成 `C² 平滑曲线`，而且 τ 自己跟着数据走，不引入新超参。

### B. 余弦被 outlier 维度绑架（`--whiten`）

残差流有几个巨型维度（attention sink / massive activation）。直接算 cos，角度基本由这十几个坐标决定，**你正则的不是语义夹角**。逐维 z-score 之后再算角度。`tests/test_geometry.py` 里有一个最小复现：原始 cos 被钉在 -0.94 / -1.00，白化后回到 -0.46 / -0.43。

### C. 采样位置决定梯度效率（`--anchors`）

后继工作算出：随机 token 采样 vs 语义步边界，同一损失函数的**有效梯度差约 100×**（168× vs 4× 的 latent MSE 提升）。本仓库支持 `random / stride / step` 三种锚点；`step` 走 `<|step|>` 或双换行切分，用在数学推理数据上。

### D. 它只约束"自己别歪"，不约束"彼此别撞"（`--repulsion`）

"防 mode collapse"是 ODE 的 Picard–Lindelöf 定理推出来的，实验只在一个合成集上验过一次。我们加 VICReg 式跨样本分离项，把这条从"理论声称"变成"显式约束 + 可测量指标"（`collision_rate`）。

### E. λ 脆得像玻璃 → 零调参（`--adaptive_lambda loss_ratio`）

论文最优 λ 跨两个数量级（Llama-3 8B 只要 0.0025，NQ-Open 要 0.16），越过拐点直接崩。改成控制器：保持几何项占总损失的固定份额 ρ，λ 由 `ρ/(1-ρ) · L_NTP/L_STP` 的 EMA 给出，并夹在 [λ₀/4, 4λ₀]。

### F.（还没做，但决定胜负）预训练 + 自然语料

论文只在**微调**上验证，却引用 **Chinchilla 预训练**定律。这是它最大的 claim–evidence 错位。谁能把 data efficiency 在 FineWeb 级语料、1B–7B 真预训练上复现出 ≥2×，就是直接把这篇按在地上。本仓库目前只搭了 SFT 路径；要扩到预训练，需要把 `span_ce` 换成全序列 CE（`chunked_ce` 已经留着），并把几何项只作用在自然段落的滑窗上。

## 3. 已经拿到的证据（单卡 Llama-3.2-1B / LoRA）

### 3.1 轨迹测量的核心事实

| 证据 | 数值 | 说明 |
|---|---|---|
| 直线假设的误差 | `mse_linear / mse_mlp` = **6.31 / 12.24 / 22.66**（m=1/2/3） | 轨迹不是直线，且跳得越远越不是 |
| `curv` vs `curv_budget` 行为差 | 0.12 rad/step 的圆弧：`curv` 罚 0.12，`curv_budget` 罚 **0** | 预算制不会和真实弯曲对着干 |
| STP aux 量级 | λ=0.02 时 aux ≈ 1.64，随训练掉到 <0.02 | 与论文"λ=0 时 L_STP≈1.4（布朗运动）"一致 |
| 白化效果 | 原始 cos −0.94/−1.00 → 白化 −0.46/−0.43 | outlier 维度确实在绑架角度 |

### 3.2 等算力 pilot（250 步、4000 样本、1 seed、300 条测试）

| arm | 1/16 数据 EM | 1/4 数据 EM | curv evidence (1/16) |
|---|---|---|---|
| `curv_budget` | **0.425** | **0.480** | 8.96 |
| `reg` | 0.400 | 0.475 | 7.58 |
| `stp` | 0.345 | 0.425 | 8.55 |

三条读数：

1. STP 在两个数据点上都**低于**朴素微调 → 在 8GB 单卡 + LoRA + 250 步这个预算下，它的增益没复现出来。
2. 曲率预算在两个点上都最高 → 方向与假设一致。
3. **STP 没有让轨迹变直**：它的 `mse_linear/mse_mlp` 并不比基线小。也就是说，论文宣称的"把轨迹压进管里"这个机制，在测量上没发生；它若有效，也是别的原因（普通正则效应）。

⚠️ 单 seed、±3.5 个点的标准误，上述只有方向性。**这正是为什么第 4 节把 5 seeds 写进判定标准。**

## 4. 什么才算"比它更强"（判定标准，先写死再跑，防止自欺）

1. **同算力同数据**下，`stpp` 的 `exact_match` ≥ `stp`，且在 1/16 数据点上差值 ≥ 2 个标准差（5 seeds）。
2. 在 1/4、1/16 两个数据点上，`stpp` 的**衰减斜率更平**——这才叫数据效率，不是单点运气。
3. `collision_rate` 不劣化（多样性不能被正则项吃掉）。
4. 至少一个**自然语料**数据集（HellaSwag / GSM8K / Spider）上复现，不能只在合成集上漂亮。
5. λ 不做逐模型扫描，直接一套参数跑完所有模型尺寸。

---

## 5. 诚实的边界

- 本仓库是单卡 LoRA，绝对分数低于论文的全量微调；只读**臂间相对差**。
- NL-RX-SYNTH 本身几何感强，1/16 在这里容易出漂亮数字；跨到自然语料前不要下结论。
- `probe.py` 的锚点是按 token 均匀取的，不是推理步边界；对数学链要换 `--anchors step`。
- 曲率预算的 τ 是 EMA 自适应，早期不稳定；如果要写论文，需要给出 τ 的收敛曲线。
